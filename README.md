## 📰 Grid Magazine

A simple and responsive Grid Magazine website built with HTML and CSS.
This project demonstrates the use of CSS Grid Layout to create a clean, structured, and modern magazine-style webpage. It focuses on layout design, responsiveness, and elegant typography.

## [LiveDemo](https://monisasmal.github.io/Grid-Magazine/)

## ✨ Features

Responsive CSS Grid layout

Clean and modern typography

Magazine-style article design

Works across desktop, tablet, and mobile

Minimal, distraction-free UI
